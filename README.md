
# Brew & Crumb POS (Mockup UI)

Tampilan awal aplikasi kasir (Point of Sale) sederhana untuk kedai kopi **Brew & Crumb**.

## Fitur Utama

- **Kasir:** Pemilihan menu dan ringkasan pesanan.
- **Produk:** Pengelolaan daftar menu (tambah dan edit).
- **Transaksi:** Riwayat pembelian dan pratinjau struk.
- **Ringkasan:** Statistik pendapatan dan diagram penjualan mingguan.
- **Pengaturan:** Kustomisasi logo, nama toko, dan tagline struk.
